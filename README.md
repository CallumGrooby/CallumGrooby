# Callum Grooby
**IT Support Enthusiast & Web Developer**
Lincolnshire, UK

## About Me
I'm working toward a career in IT support, building hands-on experience through self-directed homelab projects while keeping my web development skills sharp on the side.

My homelab work covers virtualisation, Active Directory, Linux server administration, and self-hosted services, all documented here on GitHub. I enjoy getting into the details of how systems work, troubleshooting when things break, and writing it up clearly so others can follow along.

I also build web apps using React and Node.js, and have shipped a number of full-stack projects ranging from e-commerce sites to API-driven tools. That background gives me a solid understanding of how modern software is put together, something I find useful when supporting the people who use it.

Currently studying for **CompTIA Network+**.

## Homelab & IT Projects
- **[active-directory-lab](https://github.com/callumgrooby/active-directory-lab)** — Windows Server 2025 DC, KVM/QEMU virtualisation, full AD setup with OUs, GPOs, and security groups
- **[homelab](https://github.com/callumgrooby/homelab)** — Ubuntu Server, Docker, Jellyfin, self-hosted services, LVM storage, VPN routing

## Web Projects
-  **Iron Hook** — Full-stack e-commerce site with Stripe integration, product management, and order tracking. Built with MongoDB, Express, React, and Node.js
-  **[Steam Discover](https://steam-discover.callumgrooby.co.uk/)** — Full-stack app pulling from the Steam API and Steam Spy to build a game recommendation system based on playtime, tags, and reviews
-  **[Color Shift](https://colorshift.app)** — Front-end accessibility tool for building and testing colour palettes, using the WebAIM API and Google Fonts


## Game Development
-  **Escape the Carnival** — Group project built in Unity, carnival-themed mini-games with a team of four, using GitHub for version control and collaboration
-  **Unity Development Tools** — Custom editor tools including a Dialogue Importer, Quick Placement Tool, and Camera Controller, built to explore Unity Editor scripting
-  **Natural Interactions** — Final-year VR research project comparing hand tracking vs. controller input on user presence, built in Unity with C#
